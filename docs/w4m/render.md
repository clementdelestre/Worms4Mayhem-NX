- **Particle maths** (Particle.cpp, CParticle vtable 0x860734) [disasm]: t = particle age in ms. Setup 0x5b98e0 (r uniform in [0,1)): v0 = (V + (2r−1)·Vrand)·0.01 units/ms (V is per 100 ms; IsNormalised: unit vector × (V.x + Vrand.x)); a = (A + (2r−1)·Arand)·1e-4 units/ms². Position 0x5b7450: p = p0 + v0·t + 0.5·Mass·(a + wind)·t² (Mass scales the acceleration; wind only with IsEffectedByWind). IsAlternateAcceleration: no gravity, p = p0 + v0·(N − 1/(S·t + 1/N)) (N, S = AlternateAccelerationN/S), plus v0.y·t on y. Size 0x5b6f40: fade-in, then S until SizeVelocityDelay, then linear to S·FinalSizeScale, or with FinalSizeScale 0 and SizeVelocity < 0 a linear shrink to 0 at end of life. Alpha 0x5b7660: AlphaVelocity < 0 = linear fade to 0 at end of life (magnitude ignored). - **Particle details** [disasm, 2026-10-05]:
  - Size 0x5b6f40 writes the XSpriteSet Size array (+0x48, 0x5b7ecb), which is a **half extent** (quad = position ± Size, 0x79b4f0 / 0x79bb50; "XBitmap quad size" below): a particle of Size S is 2S units across. Steps: 0 before SizeFadeInDelay (+0x5a), linear up to S at SizeFadeIn (+0x58: the absolute end of the fade, 0x5b6ad0), S until SizeVelocityDelay (+0x5c), then with u = (t − delay)/(life − delay): FinalSizeScale F ≥ 0 → S·(F·u + 1 − u); FinalSizeScale (0, 0) is replaced by −1 at setup (0x5b9a83), then per axis S + SizeVelocity·t (SizeVelocity × 0.01 per ms, t the raw age) when that velocity ≥ 0, else (1 − u)·S. S = Size + (2r − 1)·SizeRandomise (one r for both axes, 0x5b6a30); SizeVelocityRandomise y < 0 reuses x's random term (0x5b6920); delays are base + rand % (2R) − R (0x5b69b0).
  - Alpha 0x5b7660: A·t/AlphaFadeIn during the fade-in; past AlphaFadeIn + AlphaVelocityDelay, AlphaVelocity < 0 → A·(1 − (t − d)/(life − d)), AlphaVelocity ≥ 0 → A − (t − d)·AlphaVelocity (per ms); clamped to 0..1.
  - Spiral 0x5b75e0: radius r = (SpiralRadius ± rand) − SpiralRadiusSizeVelocity·0.01·t, applied (x += sin(w t)·r, z += cos(w t)·r, w = (SpiralRadiusVelocity ± rand)·0.01 per ms) only while r > 0. Wind (IsEffectedByWind) is read at each position evaluation (0x5c04f0 inside 0x5b7450), so the closed-form path follows wind changes.
  - Lifetimes: ParticleLife 65535 is an immortal particle (0x5b73d0 returns at once); EmitterLifeTime 65535 sets emitter flag 1 (0x5b9f0d), which skips the lifetime test (0x5bc016). Otherwise the emitter stops once its age passes EmitterLifeTime + LifeTimeRandomise and it has spawned its pool once (0x5bc022..0x5bc042), then waits for its particles (immortal ones: deleted at once when both values are 65535, kept while the emitter lives otherwise, 0x5bbf97).
